# HackPage — Frontend Interview Assignment

A fully responsive React + Tailwind CSS hackathon landing page.

## Features Implemented

- ✅ **Responsive Design** — mobile, tablet, and desktop layouts
- ✅ **Astronaut Animation** — floating astronaut with rotating dashed rings, radar pulse rings, and an orbiting dot
- ✅ **Interactive Timeline Slider** — drag or click to navigate hackathon schedule phases
- ✅ **Hover Animations on Images** — scale, brightness, purple overlay, and sliding label reveal
- ✅ **Custom Cursor** — dot + lagging ring follower with expand on hover
- ✅ **Scroll Reveal Animations** — IntersectionObserver staggered fade-up reveals
- ✅ **Keyboard Accessible** — all interactive elements reachable via keyboard
- ✅ **Semantic HTML5** — nav, main, section, footer, aria-labels
- ✅ **Stars Background** — procedurally generated twinkling stars
- ✅ **Particle Effects** — floating ambient particles in hero
- ✅ **Smooth Animations** — CSS keyframes + GPU-friendly transforms

## Tech Stack

- **React 19** (Vite)
- **Tailwind CSS 3**
- **Vanilla CSS** for custom animations
- **Google Fonts** — Orbitron, Exo 2, Space Mono

## Setup

```bash
npm install
npm run dev       # development server
npm run build     # production build
npm run preview   # preview production build
```

## Sections

1. **Navbar** — sticky, scroll-aware, mobile hamburger
2. **Hero** — full-screen with stats, CTAs, particles
3. **Why Participate** — animated astronaut center with benefit cards
4. **Hackathon Schedule** — interactive timeline slider
5. **Gallery** — masonry grid with cursor hover effects
6. **Rewards & Benefits** — prize podium + perks
7. **Footer** — links, email capture
